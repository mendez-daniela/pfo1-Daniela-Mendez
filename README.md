# PFO1 - Landing de Portafolio Personal

## 📝 Descripción
Landing page personal desarrollada con **HTML5 y CSS3** como parte de la PFO1 de la carrera de Desarrollo de Sistemas (ISFT N° 29). El objetivo es presentar mi perfil, formación académica, habilidades técnicas, intereses y vías de contacto con un diseño moderno de estética developer.

## 🎨 Decisiones de diseño

- **Paleta de colores**: Estética developer con fondo oscuro (`#090D16` / `#0F172A`) y acentos en gradiente índigo-violeta-rosa (`#6366F1`, `#EC4899`) y cian (`#06B6D4`), logrando alto contraste, legibilidad y un aspecto técnico y profesional.

- **Tipografía**: Google Fonts con **Plus Jakarta Sans** para títulos y textos (moderna y limpia) y **JetBrains Mono** para detalles de código, badges y etiquetas.

- **Layout**: 
  - **Flexbox** para el navbar sticky (con efecto blur), alineación de cabeceras, botones y tags.
  - **CSS Grid** para la distribución modular de tarjetas de habilidades, proyectos, intereses y formulario de contacto.

- **Secciones personales**: Sección integrada de *Intereses & Inspiración* (series y playlist musical) para mostrar el perfil humano y gustos más allá del código.

- **Responsive**: Estrategia Mobile First, variables CSS (`:root`), unidades relativas (`rem`, `%`) y media queries para adaptarse a dispositivos móviles, tablets y escritorio.
